# Officer XP Rebalance

In the base game, assigned officers only receive a share of the player's skill experience. This means long-serving officers such as Jeremy Pitt can gradually fall behind, while newly generated random officers scale with the player's current level.

This mod changes officer skill progression so that assigned officers receive the full XP for the skills associated with their role.

For example, your Navigator now receives full Sailing XP, your Treasurer full Commerce XP, your Carpenter full Repair XP, and so on.

COMPATIBILITY
Compatible with Caribbean Legend: Age of Pirates 1.2.
